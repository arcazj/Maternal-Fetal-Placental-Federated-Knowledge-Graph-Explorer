Purpose

The inspector shows metadata, URLs, available variables, access constraints, relationship edges, and implementation notes for the selected graph node.
1. Source Connectors
CDC WONDER, DASH, dbGaP, HCA, CELLxGENE, Census, EPA, FHIR, OMOP, portals.
2. Harmonization
Map raw variables to standard concepts: gestational age, birth weight, preeclampsia, placenta sample, PM2.5.
3. Ontology Layer
SNOMED CT, LOINC, HPO, Uberon, Cell Ontology, GA4GH DUO, local pregnancy ontology.
4. Knowledge Graph
Mother → Pregnancy → Placenta → Fetus/Newborn → Outcome, linked to omics, environment, social reality.
5. Privacy & Consent
Keep raw patient/genomic data local. Centralize metadata, aggregate counts, policies, and approved features.
6. Expert Explorer
Dataset discovery, relationship inspection, query templates, research design, reproducibility checks.

How to use this prototype

          
This single-file Three.js application is an expert browser for designing a federated maternal-fetal-placental knowledge graph. It uses embedded sample metadata and relationship logic to show how pregnancy outcomes, placenta biology, genetics, ancestry, environment, social context, datasets, APIs, consent rules, and standards connect.

        

        
      

      
    
        
  1. Use the left panel to search, filter domains, change access type, and switch graph layout.
    2. 
        
  2. Click any graph node or dataset card to inspect URLs, variables, relationships, access status, and implementation notes.
    3. 
        
  3. Use the bottom Mock Federated Query tab to test how dataset discovery could work.
    4. 
        
  4. Use the API / Swagger Inventory tab to review source endpoints and plan source connectors.
    5. 
        
  5. Use Export Graph JSON to save the embedded graph model for a future backend implementation.
    6. 
      

      
Privacy principle: this design centralizes metadata, ontology, access rules, aggregate counts, and approved relationships. Raw patient records, raw genomes, detailed clinical notes, and sensitive identifiers stay local or inside controlled research environments.
